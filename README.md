# 🐍 SNAKE Game

A modern, beautiful Snake game built with HTML, CSS & JavaScript featuring **smooth animations**, **sound effects**, **levels**, and **mobile support**.

![Snake Game Preview](https://via.placeholder.com/800x400/0d1117/7ee787?text=Snake+Game+Screenshot)

## ✨ Features

- **Modern Dark GitHub Theme**
- **Progressive Levels** — Speed increases every 50 points
- **Particle Effects** on eating food
- **Smooth Snake Animation** with eyes
- **High Score** (saved in browser)
- **Sound Effects** (eat, game over, level up)
- **Keyboard + Touch + Swipe** controls
- **Fully Responsive** (great on mobile)
- **Pause** with Spacebar

## 🎮 How to Play

- **Move**: Arrow Keys or WASD
- **Pause**: `Space`
- **Mute**: `M`
- **Mobile**: Use the on-screen D-Pad or swipe on the canvas

**Goal**: Eat food, grow longer, and survive as long as possible!
